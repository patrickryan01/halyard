# Halyard 1.0.1

Halyard 1.0.1 is the first release of Halyard to ship as packages for Arch, EmberRTOS Desktop and Windows, with everything in 1.0.0 and a round of polish on the details you touch most.

## What you get

Your mail, your way, in one app that is as quick and clear as Gmail on the web. It works with Google, Microsoft and any server you run yourself, with search, snooze, filters, contacts, calendars, a command line and a built-in MCP server that reads and writes every account. The notes for 1.0.0 describe each feature in full.

## Smoother every day

Adding an account keeps what you type, even while mail is syncing in the background. The search box keeps your words and your cursor when the inbox refreshes. A new message keeps the cursor in the field you picked, so your subject lands in the subject line. Sync now reports its progress accurately, from "Syncing" to "Last synced", on every account. Opening a conversation and leaving it mid-refresh is now quiet and steady.

## Install in a minute

Arch, EmberRTOS Desktop and Windows, each with the app, the command line and `mailto:` handling. On Windows the app checks the signed release and verifies it before it offers an update; on Arch and EmberRTOS Desktop your package manager keeps you current.
