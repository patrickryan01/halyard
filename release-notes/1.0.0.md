# Halyard 1.0.0

Everything a mail client should do, in one release, as easy to use as Gmail on the web and yours to run on Linux and Windows.

## Add any account in one step

Type your email address and Halyard finds the rest. Microsoft 365, Outlook.com and Hotmail sign in with one click. Gmail and Google Workspace work out of the box with a guided app password. IMAP, POP3, JMAP and self-hosted servers are found automatically. Keep every account in one combined inbox.

## Read faster

Conversations, or every message on its own. Full text search with operators (`from:` `to:` `subject:` `filename:` `label:` `is:` `has:` `before:` `after:` `larger:` `smaller:` and more), saved searches, snooze, labels and folders. Answer calendar invitations right in the message, unsubscribe from a list in one click, send and answer read receipts, see who signed a message and read encrypted mail. Remote images stay hidden until you say so.

## Write with confidence

Rich text, attachments by drop or paste, drafts kept on your server, undo send, schedule for later, templates, several identities with their own signatures, recipient suggestions, spell check, and signing and encryption with OpenPGP or S/MIME. Send to a contact group by its name. A send that fails for a temporary reason tries again by itself.

## Stay organized

Filters that run on every new message. Server-side filters over ManageSieve. An automatic reply that keeps answering while the app is closed. Rename, delete and create folders and labels, mark everything read, empty the trash in one step.

## Your contacts and calendar

Address books, groups and calendars from any CardDAV and CalDAV server.

## Move in without losing a message

Import mbox files and whole Thunderbird profiles.

## Made for every day

A command palette and keyboard shortcuts you can change, light and dark themes, an icon in the notification area, desktop notifications, an offline cache that replays your changes when you reconnect, a layout that fits a phone-sized window, and English plus Spanish, French, Italian, German, Norwegian Bokmal, Bulgarian, Greek, Korean, Japanese, Vietnamese, Hindi, Simplified Chinese and Arabic.

## Automate it

The `halyard` command line sends, searches, lists and reads from a terminal or a script. A built-in MCP server with 91 tools reads and writes every account.

## Install it your way

Arch, EmberRTOS Desktop and Windows, each with the app, the command line and the `mailto:` handler. The Windows installer is signed and checks for updates against the signed release, verifying its hash before it offers one; Arch and EmberRTOS Desktop update through the package manager.
