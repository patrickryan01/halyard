# Halyard 1.0.0

One release with everything in it.

## What is in it

* Google (Gmail API, OAuth, labels, threads, history sync, People contacts), Microsoft 365 and Outlook.com (Graph, OAuth, folders, delta sync, contacts), and self-hosted mail (IMAP with IDLE and SMTP, JMAP) as plugins behind one interface.
* Conversation threads, full text search with `from:`, `to:`, `subject:`, `is:unread`, `is:starred` and `has:attachment`, labels and folders, archive, delete, spam, snooze, undo send, drafts, a rich composer with attachments and drag and drop, signatures, a unified inbox, Gmail's keyboard shortcuts, desktop notifications, an offline cache with queued actions, contacts autocomplete, light and dark themes, and account setup from one field.
* A read and write MCP server, on by default, covering every account: 37 tools for accounts, folders, threads, search, send, reply, forward, drafts, the outbox, labels, archive, delete, snooze, attachments in and out, contacts, and settings. It needs a bearer token from the data directory and serves loopback only.
* Packages: Arch (`halyard-1.0.0-1-x86_64.pkg.tar.zst`), EmberRTOS Desktop (openSUSE Tumbleweed, `halyard-1.0.0-0.x86_64.rpm`) and Windows (`halyard-1.0.0-setup.exe`).

## Defaults

Everything finished is on: notifications, the MCP server, the offline queue. Remote images are blocked by default per message, with a Load images button, because loading them tells the sender you read the message; that is a privacy setting the person can turn on in Settings, not an unfinished feature.
