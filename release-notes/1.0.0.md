# Halyard 1.0.0

Your mail, your way, finally in one app. Halyard is as quick and clear as Gmail on the web, and it works with the accounts you already have: Google, Microsoft, and any server you run yourself. Linux and Windows, one release, nothing held back for later.

## Your inbox, set up in seconds

Type your address. Halyard works out the rest. Microsoft 365, Outlook.com and Hotmail sign in with a single click. Gmail and Google Workspace come with a guided app password that takes a minute. IMAP, POP3, JMAP and self-hosted servers are found on their own. Every account lands in one inbox.

## Find anything, answer from anywhere

Search with the operators you already know (`from:` `to:` `subject:` `filename:` `label:` `is:` `has:` `before:` `after:` `larger:` `smaller:`) and keep the searches you use most. Snooze what can wait. Accept a meeting from inside the message, leave a mailing list with one click, and see at a glance who really sent it, with signed and encrypted mail opened for you. Remote images stay hidden until you say otherwise, so nobody learns when you read.

## Writing that gets out of your way

Rich text, drag and drop attachments, drafts that follow you to the server, undo send and send later. Templates for the replies you write every week, a signature for each address you send from, suggestions as you type, spell check, and OpenPGP and S/MIME signing and encryption. Write to a group by its name. A message that can't leave right now tries again by itself.

## Rules that work while you sleep

Filters that sort every new message. Server-side filters over ManageSieve. A vacation reply that keeps answering after you close the app. Rename folders, create labels, mark a whole folder read, empty the trash in one step.

## Everything you carry with you

Contacts, groups and calendars from any CardDAV and CalDAV server. Import an mbox file or a whole Thunderbird profile and start where you left off, with every message.

## Built for every day

A command palette and shortcuts you can change to suit you. Light and dark themes, a tray icon, desktop notifications, and an offline cache that catches up the moment you reconnect. It fits a small window as well as a big one, and it speaks English, Spanish, French, Italian, German, Norwegian Bokmal, Bulgarian, Greek, Korean, Japanese, Vietnamese, Hindi, Simplified Chinese and Arabic.

## Make it yours

Send, search and read from the terminal with `halyard`. Hand your mail to your own tools through the built-in MCP server and its 91 tools, which read and write every account.

## Install in a minute

Arch, EmberRTOS Desktop and Windows, each with the app, the command line and `mailto:` handling. On Windows the app checks the signed release and verifies it before it offers an update; on Arch and EmberRTOS Desktop your package manager keeps you current.
